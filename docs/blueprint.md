# **App Name**: DailyMart

## Core Features:

- Product Browsing: Browse products by categories with images, names, weight, price, and 'Add to Cart' button.
- Location-Based Delivery: Users can select their delivery address to view available products and delivery options.
- Real-time order tracking: Enables the user to see the real-time order status with timeline of pending, packed, out for delivery and delivered updates.
- Profile Management: User can manage their profile information and addresses.

## Style Guidelines:

- Primary color: Vibrant orange (#FF8C00) to convey speed and energy.
- Background color: Light beige (#F5F5DC) for a clean and fresh feel.
- Accent color: Soft green (#90EE90) for positive actions and highlights.
- Body and headline font: 'Poppins' (sans-serif) for a modern and user-friendly interface.
- Bottom navigation bar for easy access to Home, Categories, Cart, and Profile.
- Use of rounded corners to soften the interface.
- Smooth transitions and loading animations for a fluid user experience.
